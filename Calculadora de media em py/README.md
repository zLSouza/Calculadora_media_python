# 🎓 Sistema de Notas Escolar

## 📝 Sobre o Projeto
Este é um programa desenvolvido em Python para automatizar o cálculo de médias e verificar a situação final de alunos. O sistema foi construído como parte de uma atividade acadêmica e serve como um exercício prático de lógica de programação, funções e estruturas de controle (`if/elif/else` e `match-case`).

## ⚙️ Funcionalidades
- Cadastro do nome do aluno.
- Coleta de duas notas (avaliações).
- Tela de confirmação e alteração de notas antes do cálculo.
- Cálculo automático da média.
- Classificação da situação do aluno baseada nas regras:
  - **Média > 7.0:** Aprovado 🟢
  - **Média entre 5.0 e 6.9:** Recuperação 🟡
  - **Média < 5.0:** Reprovado 🔴
- Sistema de repetição contínua: permite calcular a nota de vários alunos sem precisar reiniciar o programa.

## 🛠️ Tecnologias Utilizadas
- **Python 3.x**

## 🚀 Como Executar
1. Certifique-se de ter o [Python](https://www.python.org/) instalado em sua máquina.
2. Clone este repositório ou baixe o arquivo do código.
3. Abra o terminal e navegue até a pasta do projeto.
4. Execute o comando abaixo:
   python Calculadora_de_media.py
